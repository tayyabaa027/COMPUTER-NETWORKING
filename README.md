# 🏨 Hotel Management Network Design

A networking project that designs and implements a secure, scalable, and efficient network infrastructure for a modern hotel using Cisco Packet Tracer. The network connects multiple departments across three floors while ensuring reliable communication, security, and efficient resource management through VLAN segmentation, OSPF routing, and DHCP.

---

## 📌 Project Overview

This project demonstrates the practical implementation of enterprise networking concepts for a multi-floor hotel environment. The network is designed to support communication between departments while maintaining security, scalability, and centralized management.

---

## ✨ Features

- 🌐 Three-floor network architecture
- 🏢 Department-based VLAN segmentation
- 🔀 Dynamic routing using OSPF
- 📡 Wireless network connectivity on every floor
- 📍 Dynamic IP allocation using DHCP
- 🖨️ Shared network printers
- 🔒 Secure inter-department communication
- 📈 Scalable and organized network design

## 🌐 Network Architecture

- Three routers (one logical router per floor)
- One access switch on each floor
- Inter-router communication using Serial DCE links
- Department-based VLAN implementation
- Wireless Access Points connected to floor switches
- Centralized server room for network devices
